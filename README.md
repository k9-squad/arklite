# 方舟Lite · 极简塔防

一个类《明日方舟》的极简版塔防游戏，使用 **Svelte 5 + Vite + TypeScript** 构建，优先适配**手机竖屏**。所有单位与地图均用基础几何形状表示。

## 在线体验 / 部署（GitHub Pages）

本仓库内置 GitHub Actions 工作流 `.github/workflows/deploy.yml`，会自动构建并发布到 GitHub Pages：

1. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 把分支合并到 `main`（或在 Actions 页面手动触发 `Deploy to GitHub Pages`）。
3. 部署完成后访问 `https://<用户名>.github.io/arklite/`。

> Vite 的 `base` 已设为 `/arklite/`（见 `vite.config.ts`），与仓库名对应。若仓库改名，请同步修改该值。

## 本地开发

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器（热更新）
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览生产构建
npm run check    # svelte-check 类型检查
```

## 目录结构（功能解耦）

```
src/
├── main.ts                 # 入口，挂载 App
├── app.css                 # 全局样式
├── App.svelte              # 根组件：装配引擎 + 渲染 + 主循环 + 输入
├── ui-types.ts             # UI 层数据类型
├── game/                   # 纯逻辑引擎（无 DOM / 无框架依赖，可独立测试）
│   ├── types.ts            #   共享类型
│   ├── config.ts           #   地图、路径、经济常量
│   ├── operators.ts        #   干员定义与攻击范围
│   ├── enemies.ts          #   敌人定义
│   ├── waves.ts            #   波次生成
│   ├── geometry.ts         #   网格/朝向/范围几何（纯函数）
│   └── engine.ts           #   GameEngine：状态机与模拟单步
├── render/
│   └── renderer.ts         # 画布渲染器（唯一掌握「格↔像素」映射）
└── components/             # Svelte UI 组件
    ├── Hud.svelte          #   顶部状态栏
    ├── Dock.svelte         #   底部部署条
    ├── CardInfoModal.svelte#   干员详情弹窗（范围 + 全部说明）
    ├── OpInfoPanel.svelte  #   已部署干员信息（实时血量/攻击）
    ├── RangeGrid.svelte    #   范围可视化网格
    └── StartOverlay.svelte #   开始 / 结算覆盖层
```

**解耦要点**：`game/` 是不依赖浏览器的纯 TypeScript，可在 Node 下直接跑模拟测试；`render/` 只负责把引擎状态画到 canvas；`components/` 只负责 DOM UI 并通过回调调用引擎方法。三层互不耦合，便于维护与替换。

## 玩法

- 地图分为**地面格**（深灰，敌人行走、近战可部署）与**高台格**（蓝灰，远程可部署）。
- 敌人从**出生点(出)** 沿路径前进，进入**目标点(蓝门)** 会扣 1 点生命；生命归零即失败。击退全部波次即获胜。
- 每秒 +1 **费用**，点击干员卡 → 详情弹窗（含攻击范围与全部说明）→「部署」。
- 在格子上**按下并拖动可选择朝向**（范围随朝向旋转），松手确认；直接点按则用默认朝向。
- 点击已部署干员，弹出信息条显示其**当前生命值与攻击力**，并可**撤退**。
- 顶部可**暂停**、切换 **1x / 2x** 速度。

## 拦截与攻击规则

- 地面近战干员可阻挡一定数量敌人；**超过上限**的敌人**穿过**继续前进。
- 攻击优先级：先打**自身阻挡**的敌人，否则打范围内**最接近目标点**的敌人。
- **群法**对范围内所有敌人同时造成伤害；**医疗**治疗范围内血量百分比最低的友方。

## 五种干员

| 干员 | 形状 | 阻挡 | 范围 | 特点 | 费用 |
|------|------|------|------|------|------|
| 近卫 | 橙方块 | 1 | 1×2（含自身） | 高攻·中攻速·中血 | 17 |
| 重装 | 蓝方块 | 3 | 1×1（仅自身格） | 低攻·中攻速·高血 | 15 |
| 射手 | 绿三角 | — | 身前 3×4 | 中攻·高攻速·低血 | 16 |
| 群法 | 紫菱形 | — | 身前 3×2 区域群攻 | 高攻·慢攻速·低血 | 25 |
| 医疗 | 青圆形 | — | 身前 3×3+1 治疗 | 中疗·中攻速·中血 | 14 |

## 攻击特效

近战（近卫/重装）为弧形挥砍刀光；射手为射线；群法为范围闪光；医疗为绿色光环 + 十字。

## 数值诠释说明

原始需求中部分数值含糊，本实现采用如下诠释（其余阻挡数、费用、攻速/血量倾向严格遵循需求）：

- **射手** 范围按需求为 **3×4**（身前 3 宽 × 4 深，12 格）。
- **群法** 范围为身前 3×2 群攻，费用按需求为 **25**。
- **医疗** 范围为 **3×3 + 最前 1 格**（10 格）；其**部署费用需求未给定，取折中值 14**。
